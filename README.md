# uno_engine
Realtime Rendering Engine based on DX11
## 최종 목표 및 컨셉
- 기초에 충실한 리얼타임 유저 인터렉션 렌더링 엔진.
- 렌더링파이프라인, DX11, 기능추가보다는 성능개선에 초점(성능개선의 여지가 있다면 기능추가 보다 성능개선을 먼저한다.)
- 기능추가 후, D3D의 공식문서와 대조한다.

## 버전 기록

### v0.10 - 그림자(Shadow Map)
- 실시간 그림자맵 기능 구현

### v0.9 - PSO 및 필터링 리팩토링
- 필터링 로직 변경
- PSO(Pipeline State Object) 구조 리팩토링
- 유저 인터랙션 버그 수정
- Light 리팩토링 및 GUI 개선

### v0.8 - 유저 인터랙션
- 마우스 기반 오브젝트 피킹/인터랙션 기능 구현

### v0.7 - 거울(반사) 기능
- 스텐실 기반 거울 반사 기능 구현
- 거울 깜빡임 버그 수정

### v0.6 - Light 기능
- 조명(Light) 기능 최초 구현

### v0.5 - PBR 매핑
- BasicConstantData 구조를 PBR 매핑에 맞게 변경
- 오브젝트 PBR 적용 완료, 샘플러 추가

### v0.4 - 오브젝트 렌더링 재구축 & 포스트프로세싱 기초
- 기존 오브젝트 렌더링 코드 제거 후 재구현
- 메인 스피어에 카메라 행렬 적용 및 관련 버그 수정
- F키로 카메라 유저 입력 토글 기능 추가
- Wireframe 렌더링 옵션 추가
- PostProcessing 파이프라인 Initialize 및 렌더링 기능 구현

### v0.3 - HDRI 큐브매핑 (IBL)

- 버텍스 버퍼 - 인풋 레이아웃 불일치 버그 수정
